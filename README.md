# Prueba 3D Villa de Buitrago

Esta prueba NO consulta actas todavía.

1. Sube estos archivos a un repositorio de GitHub.
2. Ve a Actions.
3. Ejecuta manualmente `Prueba escena 3D Villa`.
4. Al terminar, descarga el artifact `villa-prueba-3d`.
5. Dentro estará `villa-prueba-3d.mp4`.

La escena usa Babylon.js para el campo y las camisetas 3D, Playwright/Chromium para capturarla y FFmpeg para convertirla a MP4.
